Making it loud

Android decides the sound, not this page. To make it a proper bell:

  1. Android Settings → Apps → Chrome → Notifications
  2. Find app.simtectp.com in the list
  3. Set it to Alerting, pick a loud tone, turn the volume up
  4. Turn on Override Do Not Disturb if you want it after hours
Save this page to your home screen first (Chrome menu → Add to Home screen). Alerts keep working with the page closed.
