SIMTEC LOYALTY / REWARDS APP — DEPLOYMENT PACKAGE (v2, complete)
================================================================
Part 1 gets PUSHED to GitHub. Parts 2 and 3 are done inside Supabase.

── PART 1 — PUSH TO GITHUB (folder 1) ──────────────────────────────────────────
Copy all 8 files into the simtec-system repo folder (root, next to your other
pages), replacing existing ones. Commit + push in GitHub Desktop. Ctrl+Shift+R.
If the app was already on your phone's home screen, remove + re-add it to pick
up the new Simtec "S" icon.

── PART 2 — RUN IN SUPABASE SQL EDITOR (folder 2) ─────────────────────────────
Run in NUMBER ORDER, one at a time. All are safe to re-run.
  01–09  the engine + every feature (01 and 07 are already live — re-running is harmless)
  10     GO-LIVE-BACKFILL — seeds every customer's points/cards/milestones from
         their payment history, so the app opens with real balances
  11     notification_events — RUN LAST. Installing before 10 would send a
         notification for every historic payment.
  PATCH  only if the engine was run before the admin-lock change (it was — run it once).

── PART 3 — EDGE FUNCTION (folder 3) ──────────────────────────────────────────
notifications-dispatch: create the function, paste the file, deploy with
Verify JWT OFF, schedule per Notifications-Setup.md. This is what actually
sends the queued SMS/emails (TNZ + Resend).

AFTER GO-LIVE: invite customers (sign-in link/QR/code), add Stripe keys when
ready, set the real review URL in rewards.html doDraw().
